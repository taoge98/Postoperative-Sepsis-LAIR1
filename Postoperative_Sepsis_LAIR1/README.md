Integrated Transcriptomic and Functional Analyses Identify LAIR1 as a Key Immunoregulatory Molecule in Postoperative Sepsis

This repository contains the R scripts used for the bioinformatic and statistical analyses associated with the manuscript:

“Integrated Transcriptomic and Functional Analyses Identify LAIR1 as a Key Immunoregulatory Molecule in Postoperative Sepsis.”

The repository is provided to facilitate transparency and reproducibility of the analyses reported in the manuscript.

---

1. Overview

The study integrates bulk transcriptomic analysis, machine-learning-based feature selection, diagnostic model evaluation, single-cell RNA sequencing, and cell-cell communication analysis to identify and characterize candidate biomarkers associated with postoperative sepsis.

The main computational analyses include:

- preprocessing and probe-to-gene annotation of public transcriptomic datasets;
- differential expression analysis;
- weighted gene co-expression network analysis (WGCNA);
- machine-learning-based feature selection using:
  - support vector machine-recursive feature elimination (SVM-RFE),
  - random forest,
  - least absolute shrinkage and selection operator (LASSO);
- expression comparison of candidate genes;
- receiver operating characteristic (ROC) analysis;
- construction and evaluation of a four-gene diagnostic model;
- nomogram, calibration, decision curve, and clinical impact analyses;
- single-cell RNA-seq preprocessing, clustering, and cell-type annotation;
- LAIR1 expression analysis in monocytes;
- correlation analysis between LAIR1 and immunoregulatory genes;
- CellChat-based intercellular communication analysis.

3. Public Datasets
The analyses were based on publicly available human transcriptomic datasets obtained from the Gene Expression Omnibus (GEO) and ArrayExpress/BioStudies.
Datasets used in the study include:
•	GSE131761
•	GSE74224
•	E-MTAB-1548
•	GSE65682
•	GSE77167
•	GSE167363
Additional validation datasets used in the manuscript should be downloaded from their original public repositories according to the accession numbers reported in the Methods and Supplementary Tables.
The original publicly available expression matrices and sequencing files are not duplicated in this GitHub repository.
Users should download the corresponding datasets and place the required files in the data/ directory before running the scripts.

4. Script Description
01_GSE131761_preprocessing.R
Preprocessing and probe-to-gene annotation of the GSE131761 expression dataset.
Main steps include:
•	loading the GEO expression matrix;
•	matching probe IDs to gene symbols using the GPL annotation file;
•	removing probes without valid gene annotations;
•	averaging multiple probes mapped to the same gene;
•	generating a gene-level expression matrix.

02_GSE131761_DEG_analysis.R
Differential expression analysis of GSE131761 using the limma package.
Differentially expressed genes were identified according to the thresholds used in the manuscript.

03_GSE74224_preprocessing.R
Preprocessing and probe-to-gene annotation of GSE74224.
The script:
•	imports the GEO expression matrix;
•	imports the GPL5175 platform annotation;
•	extracts gene-symbol information;
•	maps probes to gene symbols;
•	removes probes without valid gene annotation;
•	averages multiple probes corresponding to the same gene.

04_GSE74224_DEG_analysis.R
Differential expression analysis of GSE74224 using limma.
The comparison between sepsis and non-sepsis groups follows the parameters reported in the manuscript.

05_GSE131761_WGCNA_analysis.R
Weighted gene co-expression network analysis using the WGCNA package.
Main analysis parameters include:
•	filtering of highly variable genes;
•	sample clustering and outlier detection;
•	soft-threshold power selection;
•	unsigned network construction;
•	module identification and merging;
•	module-trait correlation analysis;
•	calculation of module membership and gene significance;
•	identification of hub genes in the selected module.
The WGCNA parameters used in this script correspond to those used in the reported analysis.

06_GSE131761_SVM_RFE_analysis.R
Feature selection using support vector machine-recursive feature elimination (SVM-RFE).
The analysis uses five-fold cross-validation to rank candidate genes and evaluate classification performance across different numbers of selected features.
The accompanying helper script:
15_msvmRFE.R
is required for this analysis.

07_GSE131761_Random_Forest_analysis.R
Random forest-based feature-selection analysis.
The workflow includes:
•	construction of an initial random forest model;
•	identification of the optimal number of trees;
•	reconstruction of the optimized model;
•	calculation of feature importance;
•	ranking of candidate genes.

08_GSE131761_LASSO_analysis.R
LASSO regression analysis using the glmnet package.
The script performs:
•	five-fold cross-validation;
•	estimation of optimal lambda values;
•	LASSO coefficient-path visualization;
•	regression coefficient extraction;
•	prediction based on the fitted model.

09_boxplot_analysis.R
Expression comparison of the four candidate genes:
•	LAIR1
•	PLAC8
•	ACSS2
•	PCOLCE2
between the corresponding clinical groups.
Statistical comparisons are performed using the same procedure described in the manuscript.
Application across multiple cohorts
The same boxplot analysis workflow was applied to the five transcriptomic cohorts used for cross-cohort expression validation.
The analytical procedure, statistical test, gene set, and plotting parameters were identical across cohorts. Therefore, a single representative script is provided rather than multiple nearly identical scripts.
For each cohort, only the following input files were changed:
1.	the cohort-specific gene-expression matrix; and
2.	the corresponding sample-group annotation file.
Thus, 09_boxplot_analysis.R represents the common analysis workflow applied independently to each cohort.

10_ROC_analysis.R
ROC analysis of the individual candidate genes and the combined four-gene diagnostic model.
The script evaluates:
•	LAIR1;
•	PLAC8;
•	ACSS2;
•	PCOLCE2;
•	the combined four-gene logistic regression model.
AUC values and confidence intervals are calculated using the pROC package.
Application across multiple cohorts
The same ROC-analysis workflow was applied independently to five transcriptomic cohorts.
Because the analytical procedure was identical across datasets, only one representative ROC script is provided.
For each cohort, the cohort-specific expression matrix was supplied as the input while the following analytical framework remained unchanged:
LAIR1
PLAC8
ACSS2
PCOLCE2
Four-gene logistic regression model
Predicted probability
ROC curve and AUC estimation
Accordingly, 10_ROC_analysis.R should be interpreted as the common ROC-analysis workflow used across the validation cohorts rather than as an analysis restricted to a single dataset.
This approach avoids unnecessary duplication of nearly identical code while preserving the exact analytical procedure used for cross-cohort validation.

11_GSE131761_nomogram_analysis.R
Construction and evaluation of the four-gene diagnostic model.
The script includes analyses related to:
•	logistic regression;
•	nomogram construction;
•	calibration analysis;
•	decision curve analysis;
•	clinical impact analysis.

12_GSE167363_single_cell_analysis.R
Single-cell RNA-seq analysis of GSE167363.
The script includes:
•	import of 10X Genomics data;
•	creation of individual Seurat objects;
•	merging of samples;
•	quality-control filtering;
•	log normalization;
•	highly variable gene identification;
•	data scaling;
•	principal-component analysis;
•	Harmony batch correction;
•	UMAP dimensionality reduction;
•	graph-based clustering;
•	marker-gene identification;
•	cell-type annotation;
•	comparison of cell-type composition;
•	visualization of LAIR1 expression;
•	analysis of LAIR1 expression in monocytes.
The sample groups include healthy controls and sepsis-related clinical groups according to the sample information used in the manuscript.

13_CellChat_HC_Sepsis_analysis.R
Cell-cell communication analysis using the CellChat package.
The analysis compares healthy-control and sepsis groups and includes:
•	inference of ligand-receptor communication probabilities;
•	pathway-level communication analysis;
•	network aggregation;
•	incoming and outgoing signaling analysis;
•	comparison of communication number and strength;
•	monocyte-centered signaling-change analysis;
•	pathway-specific visualization.
The CellChat human ligand-receptor database was used.

14_LAIR1_monocyte_correlation_analysis.R
Single-cell analysis of associations between LAIR1 and selected immunoregulatory genes in monocytes.
Genes examined include:
•	IL10
•	MRC1
•	CD163
•	CD274
The script includes:
•	exploratory cell-level Spearman correlation analysis;
•	equal-sized binning according to LAIR1 expression;
•	primary correlation analysis using 50 bins;
•	Pearson correlation analysis using bin-level mean expression;
•	sensitivity analyses using 30, 50, and 80 bins.

15_msvmRFE.R
Helper functions used by the SVM-RFE analysis.
The script is based on the implementation originally developed by John Colby:
Copyright (C) 2011 John Colby
http://github.com/johncolby/SVM-RFE
The original algorithm and analytical parameters used in the study are retained.

5. Shared Analysis Scripts Across Cohorts
Some analyses were repeated across several independent transcriptomic cohorts using the same computational procedure.
To avoid unnecessary duplication, identical scripts were not copied separately for every cohort.
Specifically:
Analysis	Script	Multi-cohort use
Candidate-gene expression comparison	09_boxplot_analysis.R	Same workflow applied independently to five cohorts
ROC analysis	10_ROC_analysis.R	Same workflow applied independently to five cohorts
For these analyses, only the cohort-specific input expression matrix and sample metadata were changed.
All statistical methods, candidate genes, model structure, and analysis parameters were otherwise retained.
This repository therefore provides the common analytical workflow rather than five redundant copies of the same script.

9. Reproducibility Notes
Relative paths
All publicly shared scripts use relative paths rather than local absolute paths.
Users should therefore run the scripts from the repository root directory.

Public datasets
Large public expression matrices and raw sequencing files are not necessarily redistributed through GitHub.
Users should obtain these files directly from GEO, ArrayExpress, or BioStudies using the accession numbers provided above and in the manuscript.

SVM-RFE
The SVM-RFE analysis depends on:
15_msvmRFE.R
which must remain in the scripts/ directory when the main SVM-RFE script is executed.

WGCNA
The WGCNA workflow includes filtering of highly variable genes, sample clustering, network construction, module identification, and hub-gene selection using the parameters specified in the corresponding script.

Single-cell RNA sequencing
GSE167363 raw sequencing files should be arranged according to the sample-folder structure expected by 14_GSE167363_single_cell_analysis.R.
The script performs preprocessing, quality control, normalization, Harmony integration, clustering, annotation, and downstream LAIR1 analyses.

CellChat
CellChat analyses can be computationally intensive.
The CellChat script generates group-specific communication networks and comparative signaling analyses based on the annotated single-cell Seurat object.
